# Установка и первый запуск

## Windows 10/11

На странице [релизов](../../../releases/latest) есть три варианта:
- `DeskRoute-Setup-<версия>.exe` — установщик: ярлыки на рабочем столе и в «Пуске», удаление через «Приложения»;
- `DeskRoute-Portable-<версия>.exe` — один файл без установки;
- `DeskRoute-<версия>-windows-x64.zip` — папка с программой: распакуйте её и запустите `DeskRoute.exe`.

Если появится «Windows защитила ваш компьютер», нажмите «Подробнее» → «Выполнить в любом случае». Ядро Xray уже внутри, настройки хранятся в `%APPDATA%\DeskRoute`.

**Права администратора.** Они нужны только для режима TUN и строгого kill switch. При подключении DeskRoute сам перезапустится с правами администратора и сразу подключится. Windows спросит разрешение один раз: создаётся задача планировщика «DeskRoute (администратор)», и дальше окно не появляется. Если вы перенесли папку с программой, разрешение спросят ещё раз.

## Arch Linux

```sh
sudo pacman -S --needed gtk3 nss alsa-lib polkit libcap nftables   # обычно уже установлены
tar -xzf DeskRoute-<версия>-linux-x64.tar.gz
cd deskroute-*/
./install.sh
```

`install.sh` копирует программу в `~/.local/share/deskroute`, добавляет её в меню приложений и создаёт команду `deskroute`. Он же регистрирует ссылки `deskroute://`. Удалить программу можно скриптом `./uninstall.sh`. Запустить без установки — `./deskroute` из распакованной папки. Есть и вариант AppImage: `chmod +x DeskRoute-<версия>-x86_64.AppImage` и запуск (в Arch для него нужен пакет `fuse2`).

- Системный прокси выставляется для GNOME и KDE Plasma. В других окружениях используйте режим «Только порт» или TUN.
- Иконка в трее в KDE работает сразу, в GNOME нужно расширение AppIndicator.
- TUN и строгий kill switch: при первом включении система спросит пароль (pkexec), чтобы выдать ядру сетевые права. Перезапускать программу не нужно.

Другие дистрибутивы на x86_64 тоже подходят: Ubuntu, Fedora, Debian и прочие.

## Первое подключение

1. Нажмите «Добавить» и вставьте ссылку на подписку от провайдера (`https://…`) или ссылки на серверы (`vless://…`, `vmess://…`, `trojan://…`, `ss://…`, `hy2://…`). Можно просто нажать `Ctrl+V` в окне программы.
2. На вкладке «Серверы» нажмите «Проверить задержку» и выберите сервер.
3. На главном экране нажмите на кольцо.

Режим «Системный прокси» подходит для браузеров и большинства программ. Для игр и программ, которые не используют прокси, включите TUN.

## Горячие клавиши

| Клавиши | Действие |
|---|---|
| `Ctrl+K` | быстрый выбор сервера |
| `Ctrl+V` | добавить ссылку из буфера |
| `Ctrl+N` | окно добавления |
| `Ctrl+1…5` | разделы |
