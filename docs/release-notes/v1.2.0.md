## Что нового
- **DeskRoute для Android.** Те же подписки, серверы, правила и оформление, что на компьютере, в виде VPN-приложения. Для телефона — своя раскладка с нижней навигацией. Ссылками `vless://`, `vmess://`, `trojan://`, `ss://`, `hy2://` и подписками можно делиться прямо в приложение. Kill switch — через системные «Постоянная VPN» и «Блокировать соединения без VPN».
- Интерфейс подстраивается под узкие экраны.

## Из версии 1.1.0
- Kill switch на Windows и Linux (мягкий и строгий).
- Совместимость с zapret / zapret-discord-youtube.
- TUN без ручного перезапуска с правами администратора.

> Windows может показать «Windows защитила ваш компьютер»: у сборки нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Android попросит разрешить установку из неизвестных источников.
