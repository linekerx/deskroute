## Что нового
- **Kill switch.** Мягкий — без прав администратора. Строгий — на весь компьютер: в Windows через брандмауэр, в Linux через nftables. После сбоя блокировка держится, пока вы её не снимете.
- **Совместимость с zapret / zapret-discord-youtube.** Discord (включая голос) и YouTube идут мимо VPN через zapret. В Linux zapret не трогает соединение с VPN-сервером, в Windows серверы добавляются в исключения zapret одной кнопкой.
- **TUN без ручного перезапуска.** В Windows DeskRoute сам получает права администратора и подключается (окно UAC только в первый раз). В Linux сетевые права ядру выдаются один раз через pkexec.

## Возможности
Подписки, как в Happ (base64, списки ссылок, JSON-конфиги Remnawave/Marzban, трафик и срок действия), VLESS/REALITY/XHTTP, VMess, Trojan, Shadowsocks, SOCKS5, Hysteria2, режимы «системный прокси», «только порт» и TUN, маршрутизация «Россия напрямую» и «только заблокированное», 10 тем и редактор всех цветов интерфейса.

> Windows может показать «Windows защитила ваш компьютер»: у сборки нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае».
