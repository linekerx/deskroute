| | `DeskRoute-1.2.1-android-universal.apk` | если не знаете, какой нужен: работает везде, весит больше |

## Что нового
- **Android:** приложение собрано под Android 15, поэтому Play Защита больше не блокирует его как «разработанное для более ранней версии Android». Интерфейс больше не залезает под строку состояния и панель навигации, а их цвет подстраивается под тему.

## Из версии 1.2.0
- **DeskRoute для Android.** Те же подписки, серверы, правила и оформление, что на компьютере. Ссылками можно делиться прямо в приложение, kill switch работает через системные «Постоянная VPN» и «Блокировать соединения без VPN».
- Kill switch на Windows и Linux, совместимость с zapret, TUN без ручного перезапуска с правами администратора.

> Windows может показать «Windows защитила ваш компьютер»: у сборки нет платной цифровой подписи. Нажмите «Подробнее» → «Выполнить в любом случае». Android попросит разрешить установку из неизвестных источников.
