Сюда кладётся ядро Xray-core для сборки.

Проще всего выполнить в корне проекта:

    npm run fetch-core

Скрипт скачает с GitHub последнюю версию и положит сюда xray.exe (или xray), geoip.dat, geosite.dat и wintun.dll.
Команды `npm run dist:*` делают это сами перед сборкой.

Если папка пустая, приложение всё равно запустится и предложит скачать ядро кнопкой.
