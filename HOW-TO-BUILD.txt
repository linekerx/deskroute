КАК СОБРАТЬ DESKROUTE ДЛЯ WINDOWS
==================================

1. Установи Node.js 22 LTS: https://nodejs.org
   При установке ничего не меняй, просто «Далее».

2. Распакуй этот архив в папку с латиницей в пути, например:
   C:\dev\deskroute

3. Открой в этой папке терминал:
   Shift + правый клик по пустому месту в папке → «Открыть в Терминале»
   (или «Открыть окно PowerShell здесь»).

4. Выполни две команды:

   npm install
   npm run dist:win

   Первая скачает Electron и сборщик (около 200 МБ, несколько минут).
   Вторая сама скачает ядро Xray с GitHub и соберёт программу.

5. Готово. В папке dist лежат:
   DeskRoute-Setup-1.1.0.exe     — установщик
   DeskRoute-Portable-1.1.0.exe  — версия без установки

Просто запустить без сборки:  npm install,  потом  npm start


ЕСЛИ ЧТО-ТО НЕ ТАК
------------------
• «Windows защитила ваш компьютер» — сборка без цифровой подписи.
  Нажми «Подробнее» → «Выполнить в любом случае».

• «npm не является командой» — закрой и заново открой терминал
  после установки Node.js.

• Ядро не скачивается (GitHub не открывается) — скачай вручную
  Xray-windows-64.zip отсюда: https://github.com/XTLS/Xray-core/releases
  Распакуй xray.exe, geoip.dat, geosite.dat, wintun.dll в папку core,
  затем выполни:  npx electron-builder --win --x64

Подробности — в README.md.
